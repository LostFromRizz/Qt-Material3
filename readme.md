# Material 3 for Qt

A QML component library for Qt Quick that provides reusable components following the [Material 3 design guidelines](https://m3.material.io/).

The library is built on top of **Qt Quick Controls** and is intended to be used directly from QML.

## What this library is

This library is **not a Qt Quick Controls style** like Basic, Fusion, Imagine, iOS, Windows, or Material. Instead, it provides a collection of individual components designed according to Material 3 guidelines.

These components can be used directly in QML applications alongside Qt Quick Controls.

## Current status

The library is still under development. Not all Material 3 components have been implemented yet.

Currently implemented components:

- Button
- Card
- CircularProgressIndicator
- CircularWavyProgressIndicator
- LinearWavyProgressIndicator
- ListItem
- LoadingIndicator
- SegmentedButton
- SegmentedListItem
- Slider
- Surface
- Switch
- SwitchDelegate
- TextField
- OutlinedTextField
- ToolTip
- TopAppBar

## Limitations

- **Icon support:** Components currently support font icons by default. Image-based icons are not supported out of the box.
- **Component coverage:** Not all components from the Material 3 guidelines are implemented yet.
